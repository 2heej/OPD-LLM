# 신경과 재진 외래 AI 문진 — 프로젝트 요약 (발표자료용)

## 한 문단 요약

외래 간호 경험에서 확인한 정보 누락, 서류 요청 지연, 보호자 단독 내원, 상담 내용 누락 문제를 바탕으로 신경과(치매·파킨슨병·뇌전증) 재진 환자 대상 AI 사전 문진을 설계하였다. 비식별 합성 사례 10건과 gold 데이터를 구축하고, 동일한 모델(gpt-4.1-mini)에서 프롬프트 v0~v3의 Exact Match, Field Accuracy, Micro F1을 비교하였다. 대표 오류를 5개 유형(누락 오류·과잉 추론·분류 오류·표현 오류·형식 오류)으로 분석해 서류·보호자 단독 내원·상담 내용 누락 방지 규칙과 증상 변화 판정 기준을 추가했으며, 개발 세트의 Exact Match가 0%에서 85.7%로, Micro F1이 0.828에서 1.000으로 개선되었다. 최종 프롬프트(v3)는 보지 않은 시험 세트 3건에서 Field Accuracy 83.3%, Micro F1 0.880을 기록했고, 남은 오류(다중 서류 요청 누락, 방문 형태 오판의 비결정성)를 후처리·UI 이중화 과제로 정리하였다. `frontend/` 문진 UI 프로토타입으로 적용 흐름을 시연하였다.

## 핵심 수치 (개발 세트 7케이스)

| 지표 | v0 | v1 | v2 | v3 |
|---|---|---|---|---|
| Exact Match | 0% | 42.9% | 42.9% | 85.7% |
| Field Accuracy | 40.5% | 76.2% | 78.6% | 92.9% |
| Micro F1 | 0.828 | 0.824 | 0.941 | 1.000 |
| 누락률 | 29.4% | 17.6% | 5.9% | 0% |
| 환각률 | 0% | 17.6% | 5.9% | 0% |
| 입력 토큰 | 2,239 | 4,598 | 5,508 | 8,861 |

시험 세트(v3, 3케이스): Exact Match 33.3%, Field Accuracy 83.3%, Micro F1 0.880. 방문 형태·증상 변화 정확도 100%.

## 발표 스토리라인

1. **문제 정의는 현장에서**: 외래 접수에서 반복되는 네 가지 문제(정보 누락, 서류 지연, 보호자 단독 내원, 상담 내용 누락)를 LLM 구조화 요약으로 완화할 수 있는지 검증. 서비스 구축이 아니라 프롬프트 설계·평가가 목적.
2. **버전별 개선 서사**: v0은 지어내지 않는 대신 못 채움(누락 지배) → v1 구조 강제로 과잉 추론 등장 → v2 불확실성 규칙으로 억제 → v3 도메인 규칙으로 누락·환각 모두 0. 개선의 대가는 입력 토큰 4배.
3. **평가가 설계를 바꾼 사례**: smoke test에서 '식사 사실 망각 악화'를 '새 증상'으로 오분류하는 것을 보고 증상 변화 판정 기준(기존 증상 악화 vs 새 증상)을 v3에 추가. 프롬프트 예시가 평가 케이스와 중복되던 데이터 누수도 발견·수정.
4. **비결정성과 이중화**: 같은 케이스("저만 왔어요")를 smoke test에서는 맞히고 본 실행에서는 틀림. 방문 형태처럼 행정·안전에 민감한 필드는 프롬프트만으로 보장할 수 없어, 문진 UI의 방문 형태 선택값을 신뢰 소스로 쓰는 이중화를 설계에 반영.
5. **UI 설계 판단**: 증상 변화(선택형)는 약 처방만 받으러 와도 확인(재진에서 "변화 없음" 확인 자체가 기록 가치), 서술형 입력은 증상 상담 선택 시에만 노출(입력 부담 최소화). 임상 안전망과 UX 부담의 절충.
